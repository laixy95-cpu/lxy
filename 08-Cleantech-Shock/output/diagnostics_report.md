## 3. 需要你决定的一个设计问题：第 5.2 节恒等式不闭合

brief 写的是"新增清洁发电 ≈ 化石发电减少 + 需求增长"。面板里可以**精确**验证（最大残差 4.5e-13 TWh）的恒等式是：

> Δ(光伏+风电) = Δ需求 − Δ净进口 − Δ化石 − Δ水电 − Δ核电 − Δ其他可再生

其中净进口 = `demand_twh − gen_twh`，62% 的观测非零。各项在分析样本内的年度变动幅度（TWh，一阶差分绝对值均值）：

| 项 | 均值 \|Δ\| |
|---|---|
| 光伏+风电（要被分解的量） | 1.05 |
| 需求 | 2.72 |
| 化石 | 2.95 |
| **净进口** | **1.02** |
| **水电** | **1.27** |
| 核电 | 0.64 |
| 其他可再生 | 0.18 |

净进口和水电的波动与被分解的量**同量级**。如果只用"化石 + 需求"两项，"每 1 TWh 新增清洁发电对应多少化石下降"这个核心数字会把进口替代、水电丰枯年波动都吸收进去，系统性偏离。

**建议做法**：用 2SLS 对上面 6 项各自回归（同一样本、同一工具变量、同一固定效应）。OLS 与 2SLS 的系数对恒等式各项具有可加性，所以六个系数会**精确**满足同一恒等式，位移比例 = −β_化石 / β_光伏风电，其余各项是它的"账平"部分。这样既保留核心数字，也能让读者看到有多少新增清洁发电其实是挤出了净进口或水电。

这需要你确认，因为它改变了第 5.2 节的表结构。在你确认之前，我没有改动 brief 的设定，该节仍按原设定保留，等数据到位后再按你的决定实现。
